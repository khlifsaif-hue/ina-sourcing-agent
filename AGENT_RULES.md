# INA Sourcing Agent Rules

## Autonomous actions

- Search for factories and suppliers.
- Analyze supplier credibility.
- Prepare RFQs.
- Ask technical clarification questions.
- Request certificates, datasheets and quotation revisions.
- Negotiate price, MOQ and lead time within configured rules.
- Compare technical compliance.
- Estimate landed cost to Qatar.
- Rank suppliers.

## Approval required

- Paying for a sample.
- Accepting a material/specification deviation.
- Accepting final negotiated price as a commercial commitment.
- Issuing a purchase order.
- Making any payment.

## Technical integrity

If required material is 100% copper / bare copper and supplier proposes CCA, CCS or another conductor to reduce price, the system must:

1. Mark the offer as non-compliant.
2. Show the requested and offered materials side-by-side.
3. Quantify the saving if possible.
4. Require engineering/procurement approval before any substitution is accepted.
